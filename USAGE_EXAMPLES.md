# 📚 Usage Examples & Tutorials

Step-by-step tutorials for common use cases with the Mobile & Tablet Mockup Generator.

## 🎯 Tutorial 1: Create Your First Mockup

**Goal**: Create a single iPhone mockup with a gradient background

### Steps:

1. **Start the Application**
   ```bash
   npm run dev
   ```
   Open http://localhost:3000

2. **Upload a Screenshot**
   - Click the "Upload Screenshots" button
   - Select an image from your computer (PNG or JPG)
   - Your image appears as a thumbnail below

3. **Select iPhone Template**
   - Click the "iPhone" tab
   - Click on "iPhone 15 Pro" card
   - The card will highlight with a checkmark

4. **View Preview**
   - Scroll to the "Preview & Adjust" section
   - Your mockup generates automatically
   - See your screenshot inside the iPhone frame

5. **Download**
   - Click "Download PNG" button
   - File saves as: `your-screenshot-iphone-15-pro.png`

**Result**: Professional iPhone mockup ready to use! ✅

## 🎯 Tutorial 2: Batch Process Multiple Screenshots

**Goal**: Create mockups for 5 app screens at once

### Steps:

1. **Upload Multiple Images**
   - Drag and drop 5 screenshots into the upload area
   - OR click "Upload Screenshots" and select multiple files
   - All 5 thumbnails appear in the grid

2. **Choose Template**
   - Navigate to "Android" tab
   - Select "Samsung Galaxy S24"

3. **Customize Background**
   - Click "Background" button
   - Choose the "Blue Gradient" preset
   - Preview updates with new background

4. **Batch Generate**
   - Scroll to "Batch Export" section
   - Click "Apply Template to All"
   - Watch progress bar: 0% → 100%
   - Success message appears

5. **Download All**
   - Click "Download All as ZIP"
   - File downloads: `mockups-[timestamp].zip`
   - Extract to find all 5 mockups

**Result**: 5 consistent mockups in seconds! ✅

## 🎯 Tutorial 3: App Store Screenshots

**Goal**: Create App Store ready screenshots for iPhone

### Recommended Setup:

**Screenshots Needed**:
- 5-10 app screens
- Resolution: 1242 × 2688 (iPhone 15 Pro Max)
- Format: PNG

### Steps:

1. **Prepare Screenshots**
   - Export from your design tool (Figma, Sketch, etc.)
   - Ensure high resolution
   - Name files descriptively (screen1.png, screen2.png, etc.)

2. **Upload All Screenshots**
   - Drag all files into upload area
   - Verify all uploaded successfully

3. **Select Device**
   - Choose "iPhone 15 Pro" (most current)
   - Matches App Store requirements

4. **Choose Background**
   - Click "Background"
   - Select "White" for clean, professional look
   - OR choose gradient for more visual appeal

5. **Generate All**
   - Click "Apply Template to All"
   - Wait for completion (shows progress)

6. **Download**
   - Click "Download All as ZIP"
   - Extract files
   - Upload to App Store Connect

**Pro Tips**:
- ✅ Use white background for App Store
- ✅ Keep consistent device across all screenshots
- ✅ Name files in order (1.png, 2.png, etc.)
- ✅ Check App Store size requirements

**Result**: App Store ready screenshots! ✅

## 💡 Pro Tips & Best Practices

### Image Quality
- **Upload**: Highest resolution possible
- **Format**: PNG for best quality
- **Size**: Under 10MB per file
- **Aspect Ratio**: Match device orientation

### Device Selection
- **iOS App**: Use iPhone templates
- **Android App**: Use Android templates
- **Universal**: Use most popular device
- **Tablet**: Use iPad Pro for premium look

### Background Choice
- **App Store**: White or light gray
- **Marketing**: Vibrant gradients
- **Portfolio**: Subtle, professional
- **Documentation**: White
- **Social Media**: Bold, eye-catching

### Batch Processing
- **Consistency**: Same device for all
- **Naming**: Use descriptive filenames
- **Organization**: Number files in order
- **Quality Check**: Preview before batch

### Export Tips
- **Individual**: For selective use
- **ZIP**: For complete sets
- **Naming**: Keep original names
- **Storage**: Organize by project

## 🐛 Troubleshooting Examples

### Issue: Mockup looks blurry
**Solution**: Upload higher resolution screenshot

### Issue: Image doesn't fit
**Solution**: Check screenshot aspect ratio matches device

### Issue: Download not working
**Solution**: Check browser pop-up blocker

### Issue: ZIP file empty
**Solution**: Click "Apply Template to All" first
